# Заметки для СИБ

## Подпись артефактов
- Lan-4Tap: артефакт `..._sign` — проверить механизм подписи.
- Docker-образы: рассмотреть Docker Content Trust / cosign.
- Прошивка: уточнить, подписана ли.

## Release vs Debug
- TPK-gate: в репозитории только debug-сборка (`..._debug_GPB`). В прод — только release, debug — только тестовый контур с обоснованием.

## TLS
- Для TMS: сертификат от внутреннего CA или Let's Encrypt; проверка срока действия; ключи не коммитить.
- Терминал подключается к TMS с `SSL: ДА` — сертификат должен быть валидным.

## Секреты
- `.env`, `appsettings.json`, ключи — только в CI/CD variables или Ansible Vault, не в Git.
- В публичном репозитории — только `.example`-файлы.

## Docker в продуктиве
- Уточнить у СИБ/архитектуры: допускается ли, есть ли registry, кто владелец Docker-хостов.
