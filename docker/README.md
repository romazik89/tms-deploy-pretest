# Контейнерный способ развёртывания TMS (Docker)

Сборка Docker-образа TMS и запуск контейнера. Учебный пример для «Пред-теста».

## Предварительные требования

- Docker Engine 24+ (или Docker Desktop для локального теста);
- доступ к образу `mcr.microsoft.com/dotnet/aspnet` (или локальная копия);
- файлы TMS (опубликованные артефакты) в папке `publish/` рядом с Dockerfile.

## Шаги (кратко)

1. Положить файлы TMS в `docker/publish/` (например, распаковать архив TMS).
2. Собрать образ: `docker build -t tms-web:2026_6_8_38158 .`
3. Запустить контейнер: `docker run -d --name tms-web -p 5000:5000 -v /data/tms:/app/data tms-web:2026_6_8_38158`
4. Проверить: `curl http://localhost:5000/`

## Важно

- Версия .NET в Dockerfile (`aspnet:7.0`) — пример. Уточните требуемую версию для вашей сборки TMS (может быть 6.0, 7.0, 8.0).
- Секреты (строка подключения к БД) передаются через переменные окружения или `appsettings.json`, не коммитятся.
- Для продакшена: многоступенчатая сборка (build + runtime), подпись образов, сканирование уязвимостей.
