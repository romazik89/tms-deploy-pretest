# Нативный способ развёртывания TMS

Установка TMS напрямую на ОС (без Docker) по руководству администратора `LANTMS_linux_1.4.pdf`.

## Предварительные требования

- Ubuntu 22.04/24.04 (или РЕД ОС);
- .NET Runtime (версия — по требованиям TMS; уточнить в руководстве);
- PostgreSQL 9.5+ (или MS SQL 2014+);
- пользователь с правами `sudo`.

## Шаги (кратко)

1. Установить .NET Runtime и PostgreSQL.
2. Создать пользователя `tmsusr` и каталоги `/opt/TMS/www`, `/opt/TMS/TmsFileStorage`.
3. Распаковать архив TMS в `/opt/TMS/www`.
4. Настроить `appsettings.json` (строка подключения к БД, путь к файлам).
5. Создать `tmsapp.service` и запустить через `systemctl`.

Подробности — в `install.sh` (учебный пример) и `tmsapp.service`.

## Важно

- `install.sh` — учебный пример, не готовый к проду. Пути и версии .NET нужно адаптировать под вашу сборку TMS.
- Секреты (пароли БД) не хранить в репозитории — использовать `.env` или переменные окружения.
